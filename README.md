# Doctor Solutions — landing page

Landing page institucional da Doctor Solutions (engenharia, infraestrutura, climatização, elétrica e manutenção predial e industrial — Nova Iguaçu, RJ).

Site estático (HTML, CSS e JS, sem build). Para publicar na Vercel, importe o repositório com o preset "Other".

- Vídeos do carrossel: adicione os arquivos em `videos/` e liste-os na constante `VIDEOS` em `script.js`.
- Prévia do link (WhatsApp/redes): `assets/og-image.jpg`. Se o domínio final for outro, troque `https://doctorsolutions.vercel.app` nas metatags do `index.html`.
